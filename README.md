# 📱 Mobile Sales Dashboard

## 📊 Project Overview

The **Mobile Sales Dashboard** is an interactive **Power BI dashboard** designed to analyze mobile phone sales performance and provide useful business insights. It helps analyze sales trends, product performance, customer behavior, and overall sales performance.

## 🎯 Objectives

* Analyze overall mobile sales performance
* Track total sales, quantity sold, and transactions
* Identify top-performing mobile brands and models
* Analyze sales trends over time
* Understand customer purchasing patterns
* Compare sales performance across locations
* Provide interactive filters for better analysis

## 🛠️ Tools & Technologies

* **Power BI**
* **Power Query**
* **DAX**
* **Data Visualization**
* **Data Cleaning & Transformation**

## 📌 Key Dashboard Features

* 📈 Sales trend analysis
* 📱 Brand and model performance
* 💰 Revenue and sales analysis
* 🛒 Quantity and transaction analysis
* 🌍 Location-wise sales analysis
* 📅 Time-based analysis
* 🔎 Interactive slicers and filters
* 📊 KPI cards and interactive charts

## 💡 Key Insights

The dashboard helps identify:

* Best-selling mobile brands and models
* Highest-performing sales periods
* Sales performance by location
* Customer purchasing trends
* Products contributing most to overall sales
